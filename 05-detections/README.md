# Detection Engineering

Status: Planned

A detection is not complete just because an SPL query returns events. Document the hypothesis, data prerequisites, test results, false positives and limitations.

Planned detections:
- Repeated failed logons in a time window
- Password spraying hypothesis
- Successful logon after repeated failures
- Suspicious PowerShell command-line patterns
- New local/domain account creation
- Privileged group membership changes
- Suspicious scheduled task creation
- Unusual network connection patterns
